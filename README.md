# Карта городских проблем — Красноярск

Житель Красноярска за минуту сообщает о проблеме городской среды — яме, неработающем фонаре, свалке, наледи, сосульках — с фото и геометкой. Обращения видны на общей карте, их можно поддержать («Я тоже видел»). Решение подтверждают сами жители: три подтверждения или фото «после», одобренное модератором.

> Приложение **не является официальным каналом обращений граждан** (59-ФЗ). Оно готовит текст обращения для платформы [«Госуслуги. Решаем вместе»](https://pos.gosuslugi.ru/).

Учебный проект СФУ, дисциплина «Разработка мобильных приложений IT-сервисов бизнес-аналитики». Команда:

- Д. Д. Кутненко — ТЗ и аналитика;
- Т. А. Гончаров — UX/UI;
- Е. В. Эбель — программист.

## Функции (по ТЗ)

- Карта Красноярска с метками по категориям и кластеризацией. Фильтры: статус, «Мои», категории, район, период.
- Список с поиском. Карточка обращения: фото, история статусов, мини-карта, ответственная организация.
- Мастер создания из 5 шагов:
  - фото с камеры или из галереи — 1–3 шт., сжатие до 1280 px, EXIF удаляется;
  - место — автогеолокация и ручная корректировка, только в границах города;
  - категория;
  - описание;
  - проверка дублей в радиусе 30 м.
- Без сети обращение становится черновиком и отправляется само, когда связь появится.
- «Я тоже видел», «Решено» / «Не решено», фото «после», жалоба на обращение.
- Текст официального обращения: копирование и переход на «Решаем вместе».
- Уведомления о смене статуса:
  - на сайте — Realtime;
  - на Android — WorkManager и локальные уведомления (FCM не используется: он требует Firebase).
- Профиль: мои и поддержанные обращения, тема, уведомления, выход, удаление учётной записи вместе с фото.
- Статистика (KPI, график за 3 недели, категории, статусы, районы, медианы) и погода Open-Meteo с предупреждением о гололёде.
- Вход:
  - **Яндекс ID** и **VK ID** — российские провайдеры (406-ФЗ);
  - **демо-вход** — анонимная сессия, чтобы проверить проект без аккаунта;
  - при первом входе — никнейм и **отдельное** согласие на обработку ПДн (152-ФЗ).
- Веб-панель модератора `#/admin`: очередь, статусы, дубли, фото «после», жалобы, блокировки, справочники, аналитика, выгрузка CSV.

## Карта всегда с подложкой

`tile.openstreetmap.org` блокирует запросы без корректных Referer или User-Agent и отдаёт картинку «Access blocked» — иногда даже с кодом 200. Поэтому:

1. Первый тайл каждого источника проверяется по пикселям: у заглушки характерная жёлто-чёрная полоса.
2. Источники перебираются по цепочке: osm.org → tile.openstreetmap.de → a.tile.openstreetmap.fr.
3. Если не отвечает ни один, показывается встроенная карта Красноярска.

На Android у osmdroid задан собственный User-Agent. CARTO не используется: требует API-ключ.

## Запуск локально

### Сайт

```bash
cd web
npm ci
npm run dev
```

Откройте <http://localhost:5173>. Чтобы подключить сервер, создайте `web/.env.local`:

```
VITE_SUPABASE_URL=https://<ref>.supabase.co
VITE_SUPABASE_ANON_KEY=<anon key>
```

Проверки:

```bash
npm run typecheck && npm run test:unit && npm run build && npm run test:e2e
```

### База данных

С Docker — локальный Supabase:

```bash
npx supabase@2.120.0 start
npx supabase@2.120.0 test db
```

Без Docker — PostgreSQL 17 + PostGIS + pgTAP и заглушка схем `auth` / `storage`:

```bash
PGBIN=/path/to/pgsql/bin bash supabase/local/run-tests.sh
```

### Android

Нужны JDK 17+ и Android SDK. Настройки сервера — в `android/local.properties`:

```
sdk.dir=...
supabase.url=https://<ref>.supabase.co
supabase.anonKey=<anon key>
site.url=https://<user>.github.io/<repo>/
```

Сборка и тесты:

```bash
cd android
./gradlew lintDebug testDebugUnitTest assembleDebug
```

APK появится в `android/app/build/outputs/apk/debug/`.

> **Windows:** Android Gradle Plugin не собирает проекты из пути с кириллицей. Подключите папку как диск, например `subst K: "C:\…\Карта городских проблем"`, и собирайте из `K:\android`.

## Как выдать роль модератора

Войдите в приложение, затем в Supabase откройте **SQL Editor** и выполните:

```sql
update public.profiles set role = 'admin' where nickname = '<ваш никнейм>';
```

- `moderator` — модерация и смена статусов.
- `admin` — то же плюс блокировки, роли и справочники.

После этого в профиле появится «Панель модератора» (сайт, `#/admin`), а в карточках — кнопки модерации.

## Ограничения

- Учебная версия использует облачный Supabase, его серверы могут находиться вне РФ.
  - Промышленная версия по ТЗ (152-ФЗ, ст. 18 ч. 5) переносится в облако на территории РФ.
  - Схема переносима: PostgreSQL + PostGIS, S3-совместимое хранилище, Edge Functions на любом Deno-хостинге.
- Полигонов районов в открытом доступе нет, поэтому район берётся из геокодера. Таблица `districts.boundary` готова к загрузке границ.
- Push-уведомлений через FCM / RuStore Push нет. Android раз в 15 минут проверяет уведомления через WorkManager, сайт получает их через Realtime.
- Размытие лиц на фото (Ф-18) и комментарии (Ф-13) имеют приоритет C и не реализованы.
- Вход через Яндекс ID / VK ID заработает после регистрации приложений у провайдеров ([MANUAL_STEPS](docs/MANUAL_STEPS.md), шаги 3–4).
