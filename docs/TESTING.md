Команды:

```bash
bash supabase/local/run-tests.sh            # pgTAP без Docker (или: npx supabase test db)
deno test --allow-env supabase/functions/
cd web && npm run typecheck && npm run test:unit && npm run test:e2e
cd android && ./gradlew lintDebug testDebugUnitTest assembleRelease
```
